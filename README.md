# Detailing Website

This is the organized version of your detailing website.

## Folder Structure

```text
detailing-website-organized/
├── index.html
├── about.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── icons/
│   │   ├── instagram.svg
│   │   └── tiktok.svg
│   └── images/
│       └── put-your-photos-here.txt
└── README.md
```

## What each file does

- `index.html` is the main homepage.
- `about.html` is a separate about page.
- `css/style.css` controls the design, colors, layout, and mobile view.
- `js/script.js` controls the menu, package popups, quote calculator, forms, and reviews.
- `assets/icons/` stores the Instagram and TikTok logo files.
- `assets/images/` is where you can add your real gallery photos.

## Netlify settings

Since this is a plain HTML website:

- Base directory: leave blank
- Build command: leave blank
- Publish directory: leave blank or use `.`
- Branch: main

## How to edit

Edit the files on GitHub or in VS Code.

Most common edits:
- Change phone number in `index.html`
- Change email in `index.html`
- Change Instagram and TikTok links in `index.html`
- Change prices in `js/script.js`
- Change colors in `css/style.css`
- Add real photos inside `assets/images/`
