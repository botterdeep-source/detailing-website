# Prestige Detailing Website

This is a simple one-page HTML website for a mobile car detailing business.

## Files

- `index.html` - Main website file

## How to edit

Open `index.html` in any code editor, like VS Code.

Things you should update:
- Business name
- Phone number
- Email
- Instagram link
- TikTok link
- Service prices
- Gallery photos
- Contact information

## How to upload to GitHub

1. Go to https://github.com
2. Click the plus button in the top right
3. Click **New repository**
4. Name it something like `detailing-website`
5. Choose **Public** or **Private**
6. Click **Create repository**
7. Upload the `index.html` file from this folder

## How to publish with GitHub Pages

1. Open your GitHub repository
2. Go to **Settings**
3. Click **Pages**
4. Under **Branch**, choose `main`
5. Choose `/root`
6. Click **Save**
7. GitHub will give you a website link
